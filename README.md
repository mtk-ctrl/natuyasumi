# NATSU//ECHO — ひと夏の残響

スマホの指一本で遊べる、Canvas製のネオン・ローグライトゲームです。

## ゲームの特徴

- 8秒間の移動が「残響」として再生され、最大3体の味方になる独自システム
- 自動射撃、敵弾、コンボ、WAVE、自動難易度上昇
- 30秒ごとに3択の能力強化を選ぶローグライト要素
- Web Audio APIによる効果音と動的BGM
- パーティクル、画面振動、発光、時間帯変化などの演出
- ハイスコア保存、結果共有、バイブレーション対応
- PWA対応でホーム画面追加・オフラインプレイ可能
- 外部ライブラリ・画像素材・音源を一切使用しない完全自立構成

## 遊び方

1. 画面を押したまま指を動かしてプレイヤーを移動します。
2. 攻撃は自動です。
3. 8秒ごとに過去の軌跡を再現する「残響」が生まれます。
4. 敵が落とす青い記憶を集めて `SUMMER BURST` を100%にします。
5. 100%になったら画面を素早く2回タップして必殺技を発動します。

## 起動

静的サイトなので `index.html` を配信するだけで動きます。GitHub Pagesにもそのまま公開できます。

ローカル確認例：

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開いてください。
